# FrameupAdtune — Digital Marketing Studio

Official website for FrameupAdtune, a boutique digital marketing studio crafting websites, brands, social media, graphic design, and paid ad campaigns.

## Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
